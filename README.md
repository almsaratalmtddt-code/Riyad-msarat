# ERP Production V1

هذه النسخة تنقل المشروع من Prototype إلى بنية ERP حقيقية:
- Next.js
- PostgreSQL عبر Prisma
- API للمبيعات والعملاء والمنتجات والمصروفات ولوحة التحكم
- إنشاء فاتورة بيع داخل Transaction
- خصم المخزون تلقائياً
- تسجيل التحصيل والذمم
- تصميم متجاوب للآيفون

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. ضع DATABASE_URL لقاعدة PostgreSQL.
3. شغّل:
   npm install
   npx prisma generate
   npx prisma migrate dev --name init
   npm run dev

ثم افتح النظام في Safari عبر رابط السيرفر.

## ملاحظة
هذه V1 للبنية الإنتاجية. يلزم في V2 إضافة القيود المحاسبية الآلية لكل نوع حركة، المشتريات الكاملة، المرتجعات، التحويلات، الصلاحيات المتقدمة، والطباعة/التقارير التفصيلية.
